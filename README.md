# Plumbline

Plumbline is a Forge app for Jira and Confluence, built for Codegeist 2026. It checks a construction RFI against what the project already decided and shows when a newer decision has replaced the old answer.

- [Privacy policy](PRIVACY.md)

- Support: open an issue at https://github.com/Class-now/plumbline/issues

The app's source is not in this repository. This repository holds the public policy pages and the support channel.
